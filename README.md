# WD4PVS / Zippy Amateur Radio — GitHub Pages

This is the corrected multi-page site for **wd4pvs.com**.

## IMPORTANT upload instructions

1. In the GitHub repository, delete the old website files (or replace them).
2. Upload **the contents of this folder**, not this folder itself.
3. Confirm these files are visible at the repository root:
   - `index.html`
   - `zippy-logo.png`
   - `styles.css`
   - `CNAME`
4. Confirm `CNAME` contains exactly `wd4pvs.com`.
5. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
6. Wait for the Pages deployment to show a green check mark in **Actions**.
7. Visit https://wd4pvs.com/?v=3 or hard-refresh with Ctrl+F5.

The logo is intentionally included both at the repository root and in `assets/`. The HTML uses the root copy so a missing `assets` upload cannot break the header logo.
