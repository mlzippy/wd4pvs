# WD4PVS / Zippy Amateur Radio — GitHub Pages Site

This is a static multi-page website ready for GitHub Pages.

## Main files
- `index.html` — Home
- `my-station.html` — My Station
- `mobile-setup.html` — Mobile Setup
- `antennas.html` — Antennas
- `radio-gear.html` — Radio Gear
- `tech-projects.html` — Technical Projects
- `arts-n4fun.html` — ARTS & N4FUN
- `gallery.html` — Gallery
- `contact.html` — Contact
- `styles.css` — Shared site styling
- `script.js` — Mobile menu and current-year footer
- `assets/` — Logo and site icons
- `.nojekyll` — Tells GitHub Pages to serve the static files directly

## Publish to GitHub Pages
1. Create a public GitHub repository.
2. Upload the **contents** of this folder so `index.html` is at the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Wait for GitHub to show the published Pages URL.

## Customize
Replace or add images in `assets/`. Edit the HTML pages with any text editor. All pages share `styles.css` and `script.js`.
