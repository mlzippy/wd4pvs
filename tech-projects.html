Project Format

Document enough to build it again.

Each project can include the goal, dimensions, parts, CAD or STEP files, wiring, photos, test results, revisions, and lessons learned.

Suggested project page contents

  • Purpose and requirements
  • Parts and materials
  • Dimensions / CAD drawings
  • Wiring or block diagram
  • Build notes and photos
  • Test procedure and results
  • Revision history
  • Downloadable STEP/STL/PDF files
